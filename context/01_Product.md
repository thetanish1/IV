# 01 Product Overview

## Vision
InternVision Tech is an ed-tech and internship portal enabling students to discover technology courses, enroll via Razorpay payments, apply for hands-on internship programs, and providing administrators with a dashboard for tracking growth and exporting records to Excel.

## Key Stakeholders
1. **Students / Users**: View catalog, enroll in courses, make payments, apply for 1/3/6-month internships.
2. **Administrators**: Authenticate securely, monitor key platform metrics, manage course offerings, inspect applications & payment histories, and export `.xlsx` reports.

## Feature Matrix
- **Public Portal**: Modern responsive Hero, Course Grid, Detailed Syllabus view, Checkout Modal, Internship Application form, Contact page, Success/Failure confirmation receipts.
- **Payment Gateway**: Razorpay Test Mode integration (order creation + server-side HMAC-SHA256 signature verification).
- **Admin Dashboard**: JWT Auth, Statistics Cards (Revenue, Applicants, Registrations), Paginated data tables, Filter & Search capabilities, Native OpenPyXL Excel Export (.xlsx).
